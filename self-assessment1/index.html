1. Page Structure & My Top 10 HTML Tags

This page itself demonstrates the required structure: a navbar above, a main header (<h1>) here, four (or more) subheaders below (<h2>), and a footer at the bottom of the screen.

My 10 most useful HTML tags

  1. <div> — generic block container, the backbone of layout.
  2. <span> — generic inline container, for styling part of text.
  3. <a> — hyperlinks, navigation.
  4. <img> — embedding images.
  5. <ul>/<ol>/<li> — lists, used constantly for nav menus and content.
  6. <form>, <input>, <button> — collecting user input.
  7. <section> / <article> — semantic grouping of content.
  8. <h1>–<h6> — headings, structure + SEO.
  9. <table>, <tr>, <td> — tabular data.
  10. <meta> — viewport, charset, SEO description, all in the <head>.

2. Important Header Tags for SEO

Search engines rely heavily on certain tags in the <head> and heading hierarchy to understand and rank a page. The most important ones:

  • <title> — shown as the clickable link in search results; single most important on-page SEO tag.
  • <meta name="description"> — the snippet text shown under the title in search results.
  • <h1> — should be used once per page, describing the main topic; a strong ranking signal.
  • <h2>–<h6> — used for subtopics, in order, to create a logical outline crawlers can parse.
  • <meta name="viewport"> — signals mobile-friendliness, a Google ranking factor.
  • <meta charset="UTF-8"> — ensures content is indexed correctly, no garbled text.
  • <link rel="canonical"> — avoids duplicate-content penalties.
  • Open Graph tags (<meta property="og:title">, etc.) — control how the page looks when shared on social media, indirectly boosting click-through rate.
  • <img alt="..."> — not a header tag, but critical: describes images for image search and accessibility.

5. Same Text, 6 Font Sizes (inline styles, absolute + relative units)

  • The quick brown fox jumps over the lazy dog. (12px — absolute)
    Use px when you need pixel-exact, non-scaling text — e.g. an icon's tiny caption or a fixed-size UI badge that must never change regardless of user/browser settings.
  • The quick brown fox jumps over the lazy dog. (18pt — absolute)
    pt (points) comes from print design; use it for content meant to be printed, like a print stylesheet for an invoice or PDF-like report.
  • The quick brown fox jumps over the lazy dog. (1.5em — relative to parent)
    Use em when a size should scale with its immediate parent — e.g. icon size inside a button that should grow/shrink with that button's own font-size.
  • The quick brown fox jumps over the lazy dog. (2rem — relative to root)
    Use rem for most responsive typography — it scales consistently off the root <html> font-size, so a user's accessibility zoom setting scales your whole site predictably.
  • The quick brown fox jumps over the lazy dog. (150% — relative to parent)
    Use % similarly to em when you want a size expressed as a percentage of the inherited font-size, e.g. making a "fine print" note 80% of body text.
  • The quick brown fox jumps over the lazy dog. (4vw — relative to viewport width)
    Use vw for text that should scale with screen width, like a big hero headline that shrinks proportionally on mobile without a media query.

6. Creative Positioning Demo (static, relative, absolute, fixed)

Below is a little "profile card" scene using four different position values. A fixed "back to top" button also floats in the corner of your browser window the whole time you scroll this page.

static (default flow)

Use when you don't need any special placement — most elements should stay static; it's predictable and doesn't remove the element from normal layout.

relative (nudged, but still holds its original space)

Use when you want to shift an element slightly from where it'd normally sit (e.g. nudge an icon 3px to align with text) — and/or to act as an anchor for an absolutely-positioned child.

absolute child →

absolute (used above): the orange badge is removed from normal flow and positioned relative to its relative parent — perfect for things like notification badges, tooltips, or dropdown menus pinned to a specific corner of a container.

↑ Top (fixed)

fixed (the "↑ Top" button): stays glued to the viewport regardless of scrolling — ideal for a persistent "back to top" button, a sticky chat widget, or a fixed navbar.
